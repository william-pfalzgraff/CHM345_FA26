# CHM345_FA26 — Modeling Earth's Climate (Fall 2026)

Course notebook site for CHM345, served as a [JupyterLite](https://jupyterlite.readthedocs.io/) static site on GitHub Pages. Students run Jupyter entirely in their browser — no installation, no server, no accounts.

- **`content/`** — everything students see in their file browser. Weekly notebook folders are added here a few days before class.
- **`requirements.txt`** — the pinned build stack. Frozen for the semester; do not upgrade mid-course.
- **`.github/workflows/deploy.yml`** — rebuilds and redeploys the site on every push to `main`.

See `INSTRUCTOR_GUIDE.md` for the weekly publishing workflow.

Only sanitized student versions of notebooks live in this repository.
